# Statistical methods: examples and simulations

Scripts, worked examples and simulations where I explore and test
different statistical methods. All data used here are simulated or
made up for illustration, no real participant data are included.

## Contents

- [`NNT_recruitment/`](NNT_recruitment/): Demonstration of using number
  needed to treat (NNT) in recruitment settings, with example data

## Usage

Each folder contains the code needed to reproduce its analysis. Developed with R version 4.5.2. 
Packages used are loaded at the top of each script or document.

## Notes

This is a personal learning and testing repository. Code is provided
as is, without any guarantee of correctness.
